# Computer Networks Project

## Project Overview

This repository contains our Computer Networks project developed and simulated using Cisco Packet Tracer.

The project demonstrates the design, configuration, and implementation of a computer network according to the specified project requirements.

## Objectives

The main objectives of this project are:

* To understand fundamental computer networking concepts.
* To design and implement a network using Cisco Packet Tracer.
* To configure and connect network devices.
* To apply appropriate networking concepts and configurations.
* To test and verify the functionality of the implemented network.

## Tools and Technologies

* Cisco Packet Tracer
* Computer Networks concepts
* Networking devices and configurations used in the project

## How to Open the Project

1. Download the `project.pkt` file from the `Packet-Tracer` folder.
2. Open Cisco Packet Tracer.
3. Open the downloaded `.pkt` file.
4. Review the network topology and configurations.
5. Test the network according to the project requirements.
